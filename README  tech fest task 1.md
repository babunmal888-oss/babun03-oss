# Techfest 30: Cyborg-Themed Landing Page

A responsive, cyborg-themed landing page for Techfest, IIT Bombay (30th edition), built with plain HTML, CSS and JavaScript. No frameworks or build step.

**Built by:** Babun Mal, Bhadrak Autonomous College (Techfest College Ambassador)

## Features
- Half-human, half-machine cyborg illustration (inline SVG) with animated rings and a pulsing optic lens
- Glitch headline, typing effect and a scanline overlay
- Animated circuit-network canvas background
- "Build your cyborg" section: toggle Optic Lens, Neural Link and Power Core, and the cyborg, power meter and status update live
- Scroll-reveal animations, hover effects and a mobile hamburger menu
- Fully responsive (phone, tablet, desktop)
- Accessible basics: semantic HTML, ARIA labels, keyboard-friendly buttons, and `prefers-reduced-motion` support

## Run it
Open `index.html` in any modern browser. An internet connection is only needed for the Google Fonts (Orbitron and Rajdhani); fallbacks are included.

## Design
- Colors: Midnight `#05070F`, Panel `#0B1224`, Cyan `#22D3EE`, Magenta `#FF2D95`, Orange `#FF8A3D`
- Fonts: Orbitron (headings), Rajdhani (body)
